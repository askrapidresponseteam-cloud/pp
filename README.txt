A Life You Recognise - Pooja Prakash

Extract the ZIP and open index.html in a browser. No installation is needed. Fonts and artwork are included.

Use the arrows, mouse wheel or journey menu to explore. The chapter menu opens genuine excerpts from the supplied manuscript. Sound is optional and starts only when enabled.
